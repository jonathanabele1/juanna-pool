# Penalties and Eligibility Reference

## Point penalties
| Violation | Penalty | Notes |
|---|---|---|
| Picks out of site order ("egregious") | Warning, then **−5 for every other offense** | Subjective; commissioner-applied |
| Weekly total 101–110 | −20 | |
| Weekly total 111–120 | −40 | +20 per additional 10 over |
| Exactly 4 double-digit picks | −20 | May not be notified |
| Forgot a game (rest sum to 100) | −20 | Per missing game |
| Missing a single game | −20 | Per missing game; reduces available points by 20 |
| Missing two games | −40 | etc. |
| Late picks (≥5 min late) | 1st: grace (0); 2nd: −10; 3rd: −20; nth: −10×(n−1) | Count shown in standings in parentheses next to name |
| Default-list member submits a pick different from the default | −10 | |
| Missing whole weekend | "a 10 or lowest weekly score" | Ambiguous |
| No pick received by Sun 1 PM ET | Lowest score for the week | No exceptions |

## Eligibility losses
| Event | Loses |
|---|---|
| Picks total < 100 (uncorrected) | "carp" award |
| Missing any game/week in the season | "carp" award |
| Any late submission | "carp" award |
| Picks not received by Sun 1 PM ET | Weekly prize that week; the resubmit courtesy once carp-ineligible |
| Entry fee unpaid by deadline | Entire participation voided |

## Lateness details
- Due **60 min before the first game of the day** (noon ET on Sundays).
- "Late" window example: noon–1:00 PM ET Sunday.
- **≥ 5 minutes late** → penalty assessed.
- Picks after kickoff are never accepted.
- Corrections after submission allowed only to fix an error so the player stays carp-eligible.

## Protests
- Two weeks to protest a weekly score; after that, the score is final.

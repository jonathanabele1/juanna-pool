# Prize Money

## Fee split (per $95 entry)
| Portion | Amount | Purpose |
|---|---|---|
| Weekly pots | $45 (18 weeks × $2.50) | Weekly prize |
| Year-end pool | $45 | Top 10 + last place |
| Remainder | $5 | Unallocated in memo (likely admin) |

## Weekly prize
- Pot = `participants × $2.50`.
- Winner = highest weekly score.
- Tiebreaker (only one): weekly win–loss record against the spread.
- Still tied → split the pot.

## Year-end prizes
Half of entry fees (stated as $45 per entry) goes to the top 10, in approximate percentages:

| Place | % | | Place | % |
|---|---|---|---|---|
| 1st | 21 | | 6th | 7 |
| 2nd | 17 | | 7th | 6 |
| 3rd | 14 | | 8th | 5 |
| 4th | 11 | | 9th | 4 |
| 5th | 9 | | 10th | 3 |

Last place ("carp"): ≈ **3%** of the final pot. Sum of listed percentages is 97 + 3 = 100.
Exact amounts depend on final participant count.

### Carp eligibility
Must have: picks for every week and every game, each week totalling exactly 100, never late.

## Payout
PayPal, or check mailed within one week after the season ends.
